# AgentMeter 0.1.0

AgentMeter 0.1.0 is the first public hobby release of the ESP32 coding-agent usage display and its
native macOS companion.

## Highlights

- Live Codex, Claude, Gemini, and Cursor quota windows and reset countdowns
- Responsive 480 × 480 AMOLED dashboard with tile and rotating full-view layouts
- Bidirectional Bluetooth settings, telemetry, reconnection, and USB fallback
- Native light and dark macOS companion with menu-bar status and local usage history
- Agent visibility, display timing, brightness, alerts, diagnostics, and device controls
- Local-first collection with bounded payloads and no cloud service operated by AgentMeter

## macOS community build

The attached Apple-silicon DMG is ad-hoc signed and is not notarized by Apple. Verify the attached
SHA-256 file, drag AgentMeter to Applications, then Control-click the app and choose **Open** on its
first launch. macOS shows this manual approval because the project does not currently use a paid
Apple Developer account.

The bundled bridge runs while the AgentMeter menu-bar application is open. Closing the main window
does not stop it; choosing **Quit AgentMeter** does. See the
[macOS companion guide](../macos-app.md) for the complete installation and security notes.

## Requirements

- Apple-silicon Mac running macOS 14 or later
- CodexBar available on the Mac
- Waveshare ESP32-S3-Touch-AMOLED-2.16 running AgentMeter firmware for device synchronization

The macOS application can display locally collected provider usage before an AgentMeter device is
connected.
