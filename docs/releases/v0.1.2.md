# AgentMeter 0.1.2

AgentMeter 0.1.2 improves Bluetooth recovery, background-bridge ownership, menu-bar usage details,
and the public project documentation.

## Highlights

- Expandable Codex, Claude, Gemini, and Cursor usage details in the menu-bar panel
- Full-width provider progress bars and a stable, scrollbar-free menu-bar presentation
- A smaller, centered Bluetooth discovery state with progress integrated into the scan button
- More reliable device discovery using the advertised `AgentMeter-XXXX` name
- One desktop bridge per application, with clean bridge shutdown from **Quit AgentMeter**
- Main-window close behavior that removes the Dock icon while preserving the menu-bar app
- A photographed project tour with current device, macOS, menu-bar, settings, and diagnostics views
- Contributor guidance covering the architecture, build sequence, media privacy, and validation

## macOS community build

The attached Apple-silicon DMG is ad-hoc signed and is not notarized by Apple. Download the DMG and
its matching `.sha256` file, verify the checksum, drag AgentMeter to Applications, then Control-click
the app and choose **Open** on its first launch.

```bash
shasum -a 256 -c AgentMeter-0.1.2-macOS-arm64-community.dmg.sha256
```

The manual approval is expected because the project does not currently use a paid Apple Developer
account. Only install artifacts from the official Prabhava Labs GitHub release with a matching
checksum.

## Compatibility

- Apple-silicon Mac running macOS 14 or later
- CodexBar available on the Mac
- Waveshare ESP32-S3-Touch-AMOLED-2.16 running AgentMeter firmware 0.1.0

This release does not require a firmware update or settings reset.
