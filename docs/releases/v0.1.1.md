# AgentMeter 0.1.1

AgentMeter 0.1.1 refines the native macOS menu-bar experience introduced in the first public
release.

## Highlights

- Modern icon-led navigation for Overview, Device and Bluetooth, Coding Agents, and Display
  Settings
- Clear visual groups for live usage, connection controls, preferences, and application actions
- Consistent full-width hit areas, hover feedback, chevrons, and native switches
- Improved device and bridge status presentation without hiding provider usage
- Content-sized menu that avoids a persistent scrollbar
- Semantic colors and native controls that remain compatible with light and dark appearances

## macOS community build

The attached Apple-silicon DMG is ad-hoc signed and is not notarized by Apple. Verify the attached
SHA-256 file, drag AgentMeter to Applications, then Control-click the app and choose **Open** on its
first launch. macOS shows this manual approval because the project does not currently use a paid
Apple Developer account.

This release does not require a firmware update. Existing devices running the AgentMeter 0.1.0
firmware remain compatible.

## Requirements

- Apple-silicon Mac running macOS 14 or later
- CodexBar available on the Mac
- Waveshare ESP32-S3-Touch-AMOLED-2.16 running compatible AgentMeter firmware
