# AgentMeter 0.2.0

AgentMeter 0.2.0 adds standalone mode, a first-class application Settings section, redesigned
desktop widgets for managed builds, and more truthful usage charts.

## Highlights

- Standalone mode: one switch turns off all Bluetooth device communication while the app keeps
  working as a desktop-only usage monitor; the choice persists across restarts
- A Settings section in the main window sidebar (⌘6) covering device sync, appearance, startup,
  and notifications — the same form as the ⌘, window
- Launch at login is registered automatically on first run of managed installs; an explicit
  Settings choice is always respected
- The Overview trend charts each agent's weekly allowance window instead of the few-hour session
  window, so lines show steady growth to the weekly reset rather than a sawtooth
- Chart points no longer spill over the axis at the range boundary
- The notification toggle now explains a denied permission and links directly to System
  Settings → Notifications instead of silently snapping back
- Provider usage windows carry meaningful kinds (Cursor total/auto/api, Gemini daily quotas,
  Claude model-specific weekly), improving window selection everywhere
- The bridge retains hourly usage points and serves them over a new bounded `history.hourly`
  command
- Managed builds gain fully redesigned Dashboard and Focus widgets: hero numbers and single
  rings, per-agent boards, a 24-hour multi-agent trend, a 30-day consumption strip, real vendor
  marks, and distance-phrased reset times ("Resets in 2 hr 5 min", "Resets Mon 6:00 PM")

## macOS community build

The attached Apple-silicon DMG is ad-hoc signed and is not notarized by Apple. It contains the
application and bundled bridge only; WidgetKit widgets require a managed, Developer ID-signed
build and are not part of the community DMG. Download the DMG and its matching `.sha256` file,
verify the checksum, drag AgentMeter to Applications, then Control-click the app and choose
**Open** on its first launch.

```bash
shasum -a 256 -c AgentMeter-0.2.0-macOS-arm64-community.dmg.sha256
```

The manual approval is expected because the project does not currently distribute with a paid
Apple Developer identity. Only install artifacts from the official Prabhava Labs GitHub release
with a matching checksum.

## Compatibility

- Apple-silicon Mac running macOS 14 or later
- CodexBar available on the Mac
- Waveshare ESP32-S3-Touch-AMOLED-2.16 running AgentMeter firmware 0.1.0

This release does not require a firmware update or settings reset. Reflashing current firmware
is optional and only refreshes the display's provider accent colors to the new palette.
