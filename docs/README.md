1. [Hardware](hardware.md) — supported board and bill of materials
2. [Setup](setup.md) — prepare the host and firmware toolchains
3. [Architecture](architecture.md) — components, data flow, and privacy boundaries
4. [Configuration](configuration.md) — providers, display, alerts, and transport
5. [Protocol](protocol.md) — host-to-device data contract
6. [Development](development.md) — repository workflow and validation
7. [Roadmap](roadmap.md) — current phase and planned milestones
